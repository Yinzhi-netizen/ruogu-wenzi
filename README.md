# 若谷问字

[[若谷]]在 iPad 上查词、在纸上写作文的小书房（纯静态 PWA）。

- **近义词**（默认首页）：可以直接说「可爱的近义词有哪些」，也可以打字；采用汉语开放词网 COW 1.1 的常用词索引，支持 7,701 个可查词，其中 6,513 个有近义表达。不同词义分组显示；另有 727 个小学写作常用词和短语的详细用法（1,454 个搭配、727 条短例句，以及逐词关联的辨析）。可按主题查词，也可点「翻词典」按拼音首字母浏览。
- **这个词怎么用**：查询详细词条时先显示所查词本身的两个搭配、例句和辨析。近义词卡、词袋也带完整用法；词典结果中有详细内容的词可点「搭配 · 例句」继续查看。写人、心情、风景、动物、动作、事情六类按页浏览。同主题的词含反义、部位等关系，明确标作主题学习，不自动认作近义词。
- **拼音和点读**：词语、搭配、已编写的例句始终显示逐字拼音；点词或搭配听读音，也可以单独听例句。词组拼音在构建时生成，复核常见多音字、轻声与助词，「一」「不」标本调。
- **词语楷体**：查询输入与显示的词头、近义词用自托管的楷体网页字体，iPad 不需要另行装字体。其他标题、说明和拼音沿用原字体。
- **我的词袋**：收藏想用的词、搭配和例句，刷新后保留；也能移出。另有最近查过的词和简短的观察提示。
- **问字**：切到「问字 · 笔顺」，按墨蓝按钮说「鲜艳的艳」，或直接打字／拼音。语音把字听成同音字时（「鲜艳的燕」），会按语境词自动纠正。
- **笔顺**：田字格里一笔一笔写给你看，也可以「跟着描」（hanzi-writer，笔顺数据在 `strokes/`，离线可用）。
- **组词**：每字约 10 个常用词，课本里学过的带 📖 排在最前。
- **字源卡**：有字源识字卡的字会出现「字源」印章，点开看故事；没有的字可以点「想听故事」，家长在「我问过的字」里复制清单。

## 数据怎么来

查词不调用 AI 或远程查询接口，词库随静态文件加载，首次打开成功并缓存后可离线查词。麦克风识别和朗读由浏览器提供；语音识别可用性取决于 iPad 浏览器、系统设置和网络，可能使用系统厂商的识别服务，不能保证离线识别。页面不录制、保存或上传语音文件。不能直接语音识别时会引导用 iPad 键盘的听写按钮。

原有数据生成：

```bash
python -I tools/ai_curate.py <原始数据目录> all   # 可选：AI 把关组词、复核词林、生成写作近义词组（结果缓存）
python -I tools/build_data.py <原始数据目录>       # 生成 data/*.js 和 strokes/
```

原始数据（不进仓库）：《通用规范汉字表》3500 一级字、jieba 词频词典、哈工大同义词词林扩展版、hanzi-writer-data、若谷课本词（星河书旅 `grade1/grade2-words.js` 导出）。

当前近义词来源为 COW，已取代原来的混合近义词生成文件作为页面查询来源。来源比较、适龄筛选局限、版本摘要与完整授权见 [词库选型与来源](词库选型与来源.md)。生成顺序：

```text
python tools/build_lexicon.py <官方 cow-1.1.tar.xz>
node tools/build_writing_pinyin.cjs
python tools/build_kai_font.py <官方 LXGWWenKaiGB-Regular.ttf> <官方 OFL.txt>
```

构建依赖为 Python 的 `pypinyin`、`jieba`、`fonttools`、`brotli`；浏览器运行不需要它们。脚本校验官方发布文件的 SHA-256，完整版权保留在 `licenses/`。

`data/writing.js` 保留原有的写作关系条目。

`data/writing-usage.js` 提供详细的词语用法，覆盖 67 个新编主题及原有 55 组中的全部词。两份文件都是原创教学补充；727 是选定常用写作词和短语的覆盖数，不是全部小学词汇总数，也不代表 7,701 个基础词库词都已有例句。每条必须有两个不同搭配、包含所查词的短例句、具体含义和辨析，不用通用句式冒充逐词例句。

修改后用安装了 `pypinyin` 的 Python 重新生成词组拼音索引：

```text
node tools/build_writing_pinyin.cjs
```

默认使用 PATH 上的 Python，也可通过 `PYTHON_BIN` 指定解释器，`PYTHONPATH` 指定构建依赖目录。页面无需安装依赖。参考插图为用户提供的书与印刷机图片，位于 `assets/文字印刷机.jpg`。

## 验收

`tools/writing.browser-test.cjs` 用隔离 Chrome、模拟语音识别和朗读测试查询、拼音、词袋重载、原有记录保留、查字笔顺、异常处理与离线，并保存 1024、768、390 像素屏宽截图。环境变量 `PLAYWRIGHT_PATH`、`CHROME_PATH`、`QA_DIR` 可指定工具和截图位置。浏览器模拟不能替代真机上麦克风授权和系统语音服务的验证。

## 加新的字源卡

把 v5 格式 JSON 放进 `cards/`，重跑 `build_data.py`，再把 `sw.js` 的 `cacheName` 和 `index.html` 里的 `?v=` 升一个版本。

## 记录

问过的字只存在这台 iPad 的 localStorage（`ruogu-wenzi-v1`），不上传。
词袋用 `ruogu-wenzi-wordbag-v1`，最近查词用 `ruogu-wenzi-words-v1`，都只在本机。更新不迁移、不重置已有查字记录，也不接触星河书旅的星星或进度。Service Worker 只清理本应用前缀的旧缓存。
