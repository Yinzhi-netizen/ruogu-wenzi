# 若谷问字

若谷写作文时查字用的 iPad 小字典（纯静态 PWA）。

- **问字**：按红色按钮说「鲜艳的艳」，或直接打字／拼音。语音把字听成同音字时（「鲜艳的燕」），会按语境词自动纠正。
- **笔顺**：田字格里一笔一笔写给你看，也可以「跟着描」（hanzi-writer，笔顺数据在 `strokes/`，离线可用）。
- **组词**：每字约 10 个常用词，课本里学过的带 📖 排在最前。
- **近义词**：点一个词，看写作文时可以换用的词；写作高频词配有孩子版解释。
- **字源卡**：有字源识字卡的字会出现「字源」印章，点开看故事；没有的字可以点「想听故事」，家长在「我问过的字」里复制清单。

## 数据怎么来

运行时不联网、不调 AI，全部数据由脚本一次性生成：

```bash
python -I tools/ai_curate.py <原始数据目录> all   # 可选：AI 把关组词、复核词林、生成写作近义词组（结果缓存）
python -I tools/build_data.py <原始数据目录>       # 生成 data/*.js 和 strokes/
```

原始数据（不进仓库）：《通用规范汉字表》3500 一级字、jieba 词频词典、哈工大同义词词林扩展版、hanzi-writer-data、若谷课本词（星河书旅 `grade1/grade2-words.js` 导出）。

## 加新的字源卡

把 v5 格式 JSON 放进 `cards/`，重跑 `build_data.py`，再把 `sw.js` 的 `cacheName` 和 `index.html` 里的 `?v=` 升一个版本。

## 记录

问过的字只存在这台 iPad 的 localStorage（`ruogu-wenzi-v1`），不上传。
